# Changelog

## 1.1.0 — 2026-10-29

- Refresh chat, inline chat, and agent session colors using a Codex-inspired dark palette.
- Align stylesheet token scopes with One Monokai and restore the JSON dictionary scope.

## 1.0.0 — 2026-10-29

- Release Story Dark Theme 1.0.0.
- Rename the extension and color theme display names to Story Dark Theme.
- Preserve the existing extension identity so installed versions receive the update.
- Update the description and documentation to reflect the One Monokai and One Dark Pro inspirations.

## 0.1.1 — 2026-10-29

- Package the current theme colors and syntax rules for the Marketplace update.
- Include the 512×512 Marketplace icon.

## 0.1.0 — 2026-10-29

- Package Story Dark as a declarative VS Code color theme.
- Refresh CSS, SCSS, LESS, and JSON token selectors.
- Replace deprecated indent guide colors and unsupported token backgrounds.
- Define colors for editor hints, sticky scroll, bracket guides, Git, diffs,
  terminal, menus, chat, agents, notebooks, and testing.
- Finalize the editor, syntax, and terminal palette for the initial release.
